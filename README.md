# Library-Book-Manager-Java
Book-Management-System-Java

## 📌 Description

A simple Java console application that demonstrates the fundamentals of Object-Oriented Programming (OOP). The program creates book objects, stores their details, and displays the information using methods.

## 🚀 Features

- Create Book objects
- Store book title, author, and price
- Display book details
- Demonstrates Classes and Objects
- Demonstrates Methods in Java

## 🛠️ Technologies Used

- Java
- Classes & Objects
- Methods
- Object Creation
